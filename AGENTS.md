# Project guidance

Keep public documentation focused on installation, architecture, API behavior,
limits and contribution guidance. Do not add personal infrastructure, account
identifiers, deployment records, local absolute paths or internal task handoffs.

If `.private/AGENTS.md` exists locally, read it for project-specific handoff
instructions. Keep these notes and their referenced files under the ignored
`.private/` directory. Never force-add this directory to Git.

The public roadmap is `docs/ideas.md`. Ideas alone do not authorize implementation.
Preserve existing changes and follow the user's requested scope.
